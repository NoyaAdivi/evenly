What's inside

Made for the end of a dinner

📸

Reads the receipt

Tesseract OCR runs in the browser, then the API finds dishes, quantities, the total and the service charge.

🍽️

Per dish or shared

Tap faces on each dish. A shared plate is split between the people who had it, untagged dishes go to everyone.

🤝

Settle up

Pick who paid and see who owes them, then send the summary on WhatsApp in one tap.

REST API

Use it from anywhere

Four endpoints, JSON in and JSON out.

GET
/This page
 GET
/healthStatus, version, commit
 POST
/api/splitSplit equally, by nights or by dishes, with tip
 POST
/api/receipt/parseReceipt text to dishes and total
terminal
curl -X POST https://splitship-1.onrender.com/api/split \
  -H "content-type: application/json" \
  -d '{"mode":"items","tipPercent":10,
       "guests":[{"name":"Noya"},{"name":"Dana"}],
       "items":[{"name":"Burger","price":62,"people":["Noya"]},
                {"name":"Fries","price":24}]}'

# response (fries are shared by both)
{ "subtotal": 86, "tip": 8.6, "total": 94.6,
  "shares": [ { "name": "Noya", "amount": 81.4 },
              { "name": "Dana", "amount": 13.2 } ] }
